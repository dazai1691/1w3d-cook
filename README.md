# 1週間献立メーカー

## 追加した機能
- 買った食材を指定して3日分の献立を生成
- 従来の1週間分モードも維持
- 料理ごとに食材の使用量を登録
- 3日分・1週間分のどちらでも食材の総使用量を買い出しリストに表示
- 料理候補の追加、レシピURL保存、編集、削除

## ファイル構成
```text
1w-dinner-menu/
├── index.html
├── app.js
├── style.css
├── README.md
└── data/
    └── recipes.json
```
`app.js`は`data/recipes.json`を読み込みます。料理追加データはブラウザのlocalStorageに保存されます。

## 食材データ
```json
{"name":"玉ねぎ","amount":"1/2個"}
```
の形式です。同じ食材で数値と単位が同じ場合は買い出しリストで合計します。
